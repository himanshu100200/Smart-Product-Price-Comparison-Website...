# Price Comparison

Frontend demo for a C++ DSA product price comparison project.

## GitHub Pages
The website files (`index.html`, `style.css`, `app.js`) are in the repository root so GitHub Pages can serve the site.

## Backend
C++ source files are stored in `backend/`. GitHub Pages is static hosting and does not compile or run the C++ backend.

## Data
The displayed catalogue, prices, ratings and review summaries are illustrative demo data. They are not live retailer prices or verified customer reviews. Retailer links open search pages. Live product search requires authorised retailer/affiliate APIs and a running backend service.
